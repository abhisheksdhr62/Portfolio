# 🚀 Abhishek Portfolio

A modern and responsive personal portfolio website built using **React + Vite**.  
This portfolio showcases my projects, skills, experience, certificates, and contact information with smooth animations and interactive UI.

## ✨ Features

- Responsive Design for all devices
- Modern UI/UX
- GSAP Scroll Animations
- Typing Text Animation
- Skills Progress Bars
- Projects Showcase
- Certificates Section
- Testimonials Section
- Contact Form with Formspree
- Resume View Option
- Interactive Hover Effects

- JavaScript
- CSS3

- React Icons
- Formspree
